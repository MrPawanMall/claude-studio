## Claude Studio by PM 2.0.1

The all-in-one companion for the Claude agent in **Antigravity, VS Code and Cursor** (previously *Claude Auto Open*).

**Install:** download `claude-studio-2.0.1.vsix` below → Extensions panel → `···` → **Install from VSIX…**

### What's inside
- 👁 Auto-open every file Claude edits, with change highlights and review markers
- 🔍 Changes panel, diff, undo one file, undo whole task, checkpoints
- ✅ PHP syntax check after each edit
- ☁️ Built-in SFTP / FTP / FTPS upload using your `.vscode/sftp.json` — auto-upload Claude's edits, upload on save, production confirmation, secure password storage, host-key verification
- 📊 Usage & cost status bar, dashboard and budget alerts (optional 5h / 7d plan usage)
- ✨ Skills manager: browse and install skills from GitHub, links, folders and .zip files with preview
- 🔔 Notifications with history and custom sounds
- 🔄 Browser live reload, ℹ️ About & credits
